### Task 2 — Group Controller

```typescript
// Body: { name: string, memberIds: string[], description?: string, avatar?: string }
```

```typescript
// 1. Verify requesting user is a ConversationMember of :id
// 2. Return conversation + all members with { userId, name, avatar, role, joinedAt }
// 3. Include lastMessage
```

#### `addMember` — POST /api/conversations/:id/members
```typescript
// Body: { userId: string }

// 2. Check target user exists in DB
// 3. Check user is not already a member (return 409 if so)
// 4. Create ConversationMember { role: 'MEMBER' }
// 5. Create SYSTEM message: `${adminName} added ${newMemberName}`
```

```typescript
// 2. Update ConversationMember.role
```

### Task 5 — Socket Auto-Join & Group Events

**File:** `server/src/sockets/socketManager.ts`

**After** `socket.join(userId)` on line 55, add auto-join for all user's conversations:
```typescript
// Auto-join all conversation rooms (needed for group broadcast)
const userConvs = await prisma.conversationMember.findMany({
  where: { userId },
  select: { conversationId: true },
});
for (const { conversationId } of userConvs) {
  socket.join(`conv:${conversationId}`);
}
```

**Update `send_message` handler** (current line 104):
```typescript
// Current (1-on-1 only):
io.to(recipientId).emit('receive_message', { message, conversationId });
socket.to(`conv:${conversationId}`).emit('receive_message', { message, conversationId });

// Replace with group-aware logic:
// For groups: only use conv room. For 1-on-1: keep recipientId room as fallback.
socket.to(`conv:${conversationId}`).emit('receive_message', { message, conversationId });
if (recipientId) {
  io.to(recipientId).emit('receive_message', { message, conversationId });
}
```

**Add new socket events** to handle:
- `group_member_update` — broadcast from REST handlers via `getIO().to(conv:id).emit(...)`
- `group_info_update` — broadcast from REST handlers via `getIO().to(conv:id).emit(...)`
- `group_created` — emit to new member's personal room so their client refreshes conversations

Note: These are emitted by REST controllers via `getIO()`, not handled as incoming socket events.
