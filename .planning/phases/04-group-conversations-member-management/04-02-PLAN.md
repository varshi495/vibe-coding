## Tasks

### Task 1 — Extend SocketContext for Groups

**File:** `client/src/context/SocketContext.tsx`

Add to the context interface and provider:

```typescript
// New group Socket events to handle:
// group_member_update → refresh conversation member list
// group_info_update   → update group name/avatar in conversation state

groupMembers: Record<string, GroupMember[]>; // conversationId → member[]
```

New exported helpers:
- `fetchGroupInfo(conversationId: string)` — GET /api/conversations/:id → store in local state.
- `addGroupMember(conversationId, userId)` — POST /api/conversations/:id/members.
- `removeGroupMember(conversationId, userId)` — DELETE /api/conversations/:id/members/:userId.
- `updateGroupInfo(conversationId, data)` — PUT /api/conversations/:id/info.

Handle incoming socket events:
```typescript
socket.on('group_member_update', ({ conversationId, members }) => {
  setGroupMembers(prev => ({ ...prev, [conversationId]: members }));
});
socket.on('group_info_update', ({ conversationId, name, avatar }) => {
  setConversations(prev => prev.map(c =>
    c.id === conversationId ? { ...c, groupInfo: { ...c.groupInfo, name, avatar } } : c
  ));
});
```
