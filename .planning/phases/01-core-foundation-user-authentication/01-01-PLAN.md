<threat_model>
- **T-01-01 (Plaintext Credential Exposure):** Passwords stored directly in database. Mitigation: Enforce bcrypt hashing with 10 salt rounds before `prisma.user.create`.
- **T-01-02 (Weak Secret / Token Tampering):** Default or empty JWT secret. Mitigation: Require `JWT_SECRET` in environment variables with safe dev fallback; sign tokens with HS256 and 7-day expiry.
- **T-01-03 (Account Enumeration / Injection):** SQL injection or verbose credential error leaks. Mitigation: Use parameterized queries via Prisma ORM and return uniform "Invalid identifier or password" on authentication failures.
</threat_model>

    2. In `server/src/middleware/authMiddleware.ts`: Check `req.headers.authorization` for `Bearer <token>`. Attach `req.userId` or return 401 Unauthorized if missing/invalid.
    3. In `server/src/controllers/authController.ts`:
       - `register`: Validates name, identifier (email or phone), password (min 6 chars). Hashes password with `bcrypt.hash(password, 10)`. Checks for existing user with same email/phone. Creates user with default avatar (e.g. initials SVG or dicebear) and default status bio. Returns 201 with JWT and sanitized user (no password).
       - `login`: Accepts `identifier` (email or phone) and `password`. Finds user matching email OR phone. Compares password with `bcrypt.compare`. Returns 200 with JWT and sanitized user, or 401 on mismatch.
       - `getMe`: Returns current user from `req.userId`.
       - `updateProfile`: Allows authenticated user to update `name`, `status`, or `avatar`.
    4. In `server/src/routes/authRoutes.ts`: Wire up `POST /register`, `POST /login`, `GET /me` (protected), `PUT /profile` (protected).
    5. In `server/src/server.ts`: Initialize Express app, enable `cors()`, `express.json()`, mount `/api/auth` routes, and export `app` / listen on `PORT`.
