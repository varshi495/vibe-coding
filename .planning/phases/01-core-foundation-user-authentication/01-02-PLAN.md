<task type="auto">
  <name>Task 2: Implement API service and AuthContext with session persistence</name>
  <files>client/src/types/auth.ts, client/src/services/api.ts, client/src/context/AuthContext.tsx</files>
  <read_first>.planning/phases/01-core-foundation-user-authentication/01-CONTEXT.md</read_first>
  <action>
    1. In `client/src/types/auth.ts`: Define `User` interface (`id`, `name`, `email`, `phone`, `avatar`, `status`, `lastSeen`) and `AuthResponse` (`user`, `token`).
    2. In `client/src/services/api.ts`: Build typed fetch wrapper that automatically attaches `Authorization: Bearer <token>` from `localStorage.getItem('chat_token')` and parses JSON responses and HTTP errors.
    3. In `client/src/context/AuthContext.tsx`:
       - State: `user: User | null`, `token: string | null`, `isLoading: boolean`.
       - On mount: checks `chat_token`. If present, calls `/api/auth/me`. If valid, sets user; if invalid, clears token.
       - `login(identifier, password)`: calls `/api/auth/login`, stores token in `localStorage`, updates user state.
       - `register(name, identifier, password)`: calls `/api/auth/register`, stores token, updates user state.
       - `updateProfile(data)`: calls `PUT /api/auth/profile`, updates local user state.
       - `logout()`: removes token from `localStorage`, resets user state to null.
  </action>
  <verify>cd client && npx tsc --noEmit</verify>
  <acceptance_criteria>
    - AuthContext provides login, register, logout, updateProfile, user, and isLoading
    - Token persists to and loads from localStorage
  </acceptance_criteria>
  <done>Auth context and API communication service completed</done>
</task>
