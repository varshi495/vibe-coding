  };

}

### Task 3 — SocketContext Provider

**File:** `client/src/context/SocketContext.tsx`

Responsibilities:
- Create Socket.IO connection on mount using `io('http://localhost:5000', { auth: { token } })` from `AuthContext`.
- Manage connection state: `connected: boolean`.
- Handle `receive_message` event: append to active conversation's message list.
- Handle `message_ack` event: replace tempId bubble with confirmed message.
- Expose `sendMessage(conversationId, recipientId, content)` which generates a `tempId`, appends optimistic bubble, then emits `send_message`.
- Expose `conversations: Conversation[]` with loading state, fetched from `GET /api/conversations` on mount and refreshed on `receive_message`.
- Expose `activeConversationId: string | null` and `setActiveConversation(id)`.
- Expose `messages: Record<conversationId, Message[]>` map.
- Expose `loadMessages(conversationId)` which fetches `GET /api/conversations/:id/messages` and stores in the map.
- On `receive_message`: update the conversation list's last message preview and increment unread count if conversation is not currently active.
- Disconnect socket on unmount / logout.

Key implementation notes:
- Wrap in try/catch for all socket emits.
- Use `useCallback` for `sendMessage` and `loadMessages` to prevent re-render cascades.
- Export `SocketProvider` component wrapping children + `useSocket` hook.

### Task 5 — ChatList Component

**File:** `client/src/components/chat/ChatList.tsx`

Structure:
```
<aside class="chat-list-panel">
  <ChatListHeader />          // User avatar, "ChatApp" title, icons (NewChat, Search)
  <SearchBar />               // Glassmorphic search input filtering conversations
  <ConversationList />        // Scrollable list of ConversationRow items
</aside>
```

**ChatListHeader:**
- Left: clickable user `<Avatar>` opens ProfileDrawer.
- Right: pencil/new-chat icon button (`PenSquare` from Lucide) → opens NewChatPanel.
- Search icon → toggles SearchBar focus.

**SearchBar:**
- Input: `rgba(32, 44, 51, 0.6)`, backdrop `blur(8px)`, border `#222e35`, placeholder "Search or start new chat".
- Filters `conversations` array from SocketContext by `otherMember.name`.

**ConversationRow (per conversation):**
- Height: `72px`, flex, items-center, padding `0 12px`.
- Left: `<Avatar name={otherMember.name} src={otherMember.avatar} size="md" />` (40px).
- Middle: contact name in `#e9edef 15px 600`, last message preview in `#8696a0 14px` truncated.
- Right: formatted timestamp (`date-fns` `formatDistanceToNow` or `format`), unread badge (`#00a884` pill).
- Active state: background `#2a3942`. Hover: `#202c33`.
- On click: `setActiveConversation(conversation.id)` + `loadMessages(conversation.id)`.

**NewChatPanel (slide-in overlay):**
- Header "New Message" + close X.
- Search input calling `GET /api/users/search?q=<term>` debounced 300ms.
- Results list: user rows with avatar + name + status.
- On user row click: `POST /api/conversations { recipientId }` → then `setActiveConversation(id)` + close panel.
