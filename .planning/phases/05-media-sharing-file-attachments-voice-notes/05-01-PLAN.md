### Task 2 — Extend Prisma Schema
**File:** `server/prisma/schema.prisma`

Extend `MessageType` enum:
```prisma
enum MessageType {
  TEXT
  SYSTEM
  IMAGE
  VIDEO
  AUDIO
  DOCUMENT
}
```

Extend `Message` model:
```prisma
model Message {
  id             String        @id @default(uuid())
  conversationId String
  senderId       String
  content        String        // caption, text, or fallback filename
  type           MessageType   @default(TEXT)
  mediaUrl       String?       // path or URL to media asset
  mediaType      String?       // MIME type (e.g., image/jpeg, audio/webm)
  fileName       String?       // original uploaded filename
  fileSize       Int?          // size in bytes
  status         MessageStatus @default(SENT)
  createdAt      DateTime      @default(now())
  updatedAt      DateTime      @updatedAt
  conversation   Conversation  @relation(fields: [conversationId], references: [id], onDelete: Cascade)
  sender         User          @relation("SentMessages", fields: [senderId], references: [id], onDelete: Cascade)
}
```

Run database migration & generator:
```bash
npx prisma db push
npx prisma generate
```

### Task 3 — Media Service & Multer Middleware
**New File:** `server/src/middleware/uploadMiddleware.ts`

- Configure disk storage to `uploads/` folder with safe unique filenames (`${Date.now()}-${uuid()}-${safeFilename}`).
- File size limit: 25MB (`25 * 1024 * 1024` bytes).
- MIME type validation:
  - Images: `image/jpeg`, `image/png`, `image/webp`, `image/gif`, `image/svg+xml` -> `IMAGE`
  - Videos: `video/mp4`, `video/webm`, `video/quicktime`, `video/x-matroska` -> `VIDEO`
  - Audios: `audio/webm`, `audio/mp4`, `audio/mpeg`, `audio/ogg`, `audio/wav`, `audio/aac` -> `AUDIO`
  - Documents: `application/pdf`, `application/msword`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document`, `text/plain`, `application/zip`, `application/vnd.ms-excel`, `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` -> `DOCUMENT`
- Reject unsupported MIME types with descriptive `400 Bad Request`.
- Handle Multer `LIMIT_FILE_SIZE` errors with `413 Payload Too Large` ("File size exceeds 25MB limit").

### Task 4 — Media Controller & Routes
**New File:** `server/src/controllers/mediaController.ts`
**New File:** `server/src/routes/mediaRoutes.ts`

Endpoints:
1. `POST /api/media/upload` (Authenticated, multipart `file`)
   - Validates uploaded file exists.
   - Computes `messageType` based on MIME type.
   - Generates relative and absolute URL (e.g., `/uploads/filename`).
   - Returns:
     ```json
     {
       "url": "/uploads/1728300000-sample.png",
       "fileName": "sample.png",
       "fileSize": 1048576,
       "mediaType": "image/png",
       "messageType": "IMAGE"
     }
     ```
2. `POST /api/conversations/:id/messages/media` (Authenticated)
   - Body: `{ mediaUrl, mediaType, fileName, fileSize, type, caption? }`
   - Verifies requesting user is member of conversation.
   - Creates Message with media fields.
   - Updates `conversation.updatedAt`.
   - Emits `receive_message` to `conv:<conversationId>` room (and recipient if 1-on-1).
   - Returns created message.
