# Plan 05-02: Client Media Picker, Voice Recorder, Lightbox & Media Messages

**Phase:** 05 — Media Sharing, File Attachments & Voice Notes
**Plan:** 05-02 of 02
**Mode:** MVP vertical slice
**Estimated effort:** Medium (3–4 hours)

---

## Goal

Deliver a WhatsApp-grade rich media frontend experience:
1. Interactive attachment popup menu (`📎`) for Images, Videos, and Documents.
2. Direct in-browser microphone voice note recording (`🎙️`) with live timer, cancel trash, and send actions.
3. In-chat media message renderers:
   - **Images**: Crisp rounded thumbnails with aspect ratio preservation, click to view in full-screen Lightbox.
   - **Videos**: Inline HTML5 video player with dark theme controls.
   - **Documents**: File icon card showing file name, formatted size (KB/MB), and instant download button.
   - **Voice Notes**: WhatsApp-inspired audio player with play/pause button, progress bar, and duration indicator.
4. Full-screen Lightbox modal with download and close controls.
5. Sidebar `ChatList` last message previews showing media type icons (`📷 Photo`, `🎥 Video`, `🎙️ Voice message`, `📄 Document`).

### Task 2 — Attachment Menu Popover
**New File:** `client/src/components/chat/AttachmentMenu.tsx`

- Animated floating popover above the `📎` paperclip button.
- Options:
  1. **Photos & Videos** (`Image` icon, purple/indigo button accent) -> opens hidden file picker with `accept="image/*,video/*"`.
  2. **Document** (`FileText` icon, blue button accent) -> opens hidden file picker with `accept=".pdf,.doc,.docx,.txt,.zip,.xlsx,.xls"`.
- Clicking an option triggers the corresponding file input and closes the popover.

---

### Task 3 — Voice Recorder Component
**New File:** `client/src/components/chat/VoiceRecorder.tsx`

- Uses `navigator.mediaDevices.getUserMedia({ audio: true })` and `MediaRecorder`.
- Features:
  - Live recording duration counter (`0:01`, `0:05`, `0:23`...).
  - Red pulsing recording dot indicator.
  - Animated audio waveform bar visualizer (pulsing CSS bars or canvas representation).
  - Cancel button (`Trash2` icon) -> aborts recording and stops media stream.
  - Send button (`SendHorizonal` icon) -> stops recording, packages chunks into `audio/webm` Blob, triggers upload, and emits `AUDIO` message.
- Graceful error handling for microphone permissions rejected.

### Task 6 — Media Message Bubble Renderer
