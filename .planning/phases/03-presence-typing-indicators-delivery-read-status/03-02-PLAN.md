# Plan 03-02: Client Presence Hooks, Typing Indicators & Checkmark Receipt UI

**Phase:** 03 — Presence, Typing Indicators & Delivery/Read Status
**Plan:** 03-02 of 02
**Mode:** MVP vertical slice
**Estimated effort:** Medium (3–4 hours)
**Depends on:** 03-01 complete (Backend socket presence, typing, and status update handlers operational)

---

## Goal

Integrate live presence, debounced typing feedback, and checkmark read receipts (`SENT` single check, `DELIVERED` double gray check, `READ` double blue check) into the React client interface.

---

## Design Reference

**Obsidian Whisper / WhatsApp Checkmark Standard**:
- Single Gray Check (`✓`): Sent to server. Icon: Lucide `Check` in `#8696a0`.
- Double Gray Check (`✓✓`): Delivered to recipient. Icon: Lucide `CheckCheck` in `#8696a0`.
- Double Blue Check (`✓✓`): Read by recipient. Icon: Lucide `CheckCheck` in `#53bdeb` or `#00a884`.

---

## Tasks

### Task 1 — Presence & Typing State in SocketContext

**File:** `client/src/context/SocketContext.tsx`

Expose new context state and methods:
- `onlineUsers`: `Record<string, { isOnline: boolean; lastSeen?: string }>`
- `typingUsers`: `Record<string, boolean>` (mapped by `conversationId`)
- `sendTypingStart`: `(conversationId: string, recipientId: string) => void`
- `sendTypingStop`: `(conversationId: string, recipientId: string) => void`
- Listen for `user_presence` socket events and update `onlineUsers`.
- Listen for `user_typing` socket events and update `typingUsers[conversationId]`.
- Listen for `message_status_update` socket events and update local message status in state.
- Auto-emit `mark_delivered` upon receiving `receive_message`.

---

### Task 2 — ComposeBar Debounced Typing Handler

**File:** `client/src/components/chat/ActiveChat.tsx`

- On input `onChange`:
  - Call `sendTypingStart(activeConversationId, recipientId)`.
  - Set / reset a 3-second `setTimeout` to automatically call `sendTypingStop`.
- On message submit / send:
  - Clear typing timeout immediately and call `sendTypingStop`.

---

### Task 3 — Header & ChatList Typing / Presence UI

**File:** `client/src/components/chat/ActiveChat.tsx` & `client/src/components/chat/ChatList.tsx`

- Update `ChatHeader` in `ActiveChat.tsx`:
  - If contact is typing: show animated "typing..." subtitle in `#00a884` emerald.
  - Else if contact is online: show "online" in `#00a884`.
  - Else: show "last seen [formatted date-fns time]".
- Update `ConversationRow` in `ChatList.tsx`:
  - If contact is typing in this conversation: show "typing..." in green text instead of last message preview.

---

### Task 4 — Message Bubble Status Checkmark Component

**File:** `client/src/components/chat/ActiveChat.tsx` or new `client/src/components/chat/MessageReceipt.tsx`

- Render status icon based on `msg.status`:
  - `PENDING`: `Clock` icon (animating/pulsing).
  - `SENT`: Single `Check` icon in `#8696a0`.
  - `DELIVERED`: Double `CheckCheck` icon in `#8696a0`.
  - `READ`: Double `CheckCheck` icon in `#53bdeb` (sky blue) or `#00a884` (emerald).

---

### Task 5 — Auto Read Receipt Trigger

**File:** `client/src/components/chat/ActiveChat.tsx`

- When user selects a conversation or receives a message in an active open chat:
  - Call `loadMessages(conversationId)` or `markAsRead(conversationId)`.
  - Emits read receipt to server, updating DB and notifying the sender in real time.
